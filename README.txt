HSC FOCUS APP — ONE-LAPTOP EDITION

1. Move the entire HSC-Focus-App folder somewhere permanent, such as Documents.
2. Double-click HSC-Focus-App.html and open it in Chrome, Edge, Firefox or Safari.
3. Keep using the same file, location and browser. The app saves locally in that browser.
4. Open Settings and download a complete backup regularly. It includes documents, photos,
   progress and deleted records. Store that backup somewhere outside this folder.

Start on My day and press Create my day. The app chooses core work based on open reviews,
recent subject coverage and your priorities. Use Papers for attempt → marking → diagnosis → retry.

DOCUMENTS
PDF, DOCX, TXT, MD, CSV, APKG, COLPKG, JPG, PNG and WebP files up to 25 MB can be stored.
PDFs, images and text can be previewed. Word and Anki files open in their usual programs.

NO AI BILL
There is no paid API and no automatic marking. Ask ChatGPT prepares a prompt for you to copy;
you attach the image in ChatGPT and paste useful feedback back into the app.

IMPORTANT
Private/incognito mode or clearing browser/site data can erase local records. A complete backup
is the reliable way to move or recover the app. A records-only export does not include files.
